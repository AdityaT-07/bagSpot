# 🛍️ bagSpot – Online Bag Shopping Platform

**bagSpot** is a full-stack web application designed for browsing and purchasing different types of bags such as backpacks, handbags, travel bags, and office bags. The platform focuses on a clean UI, smooth navigation, and a simple shopping experience.

## 📖 About the Project

The goal of **bagSpot** is to provide users with a simple and user-friendly online shopping experience for bags. It allows users to browse products, view details, and interact with a clean and responsive interface.  
This project is built as part of learning **full-stack web development using Node.js and Express**.

---

## ✨ Features

- 👜 Browse different categories of bags  
- 📄 View product details (price, description, images)  
- 🎨 Clean and responsive UI  
- ⚡ Fast server-side rendering using EJS  
- 🔐 Scalable backend structure  
- 🧩 Modular MVC architecture
